# JobTrack frictions
Every friction the owner notes goes here, with its full-convenience fix. Status: TODO / DONE.
## From the ORP Lausanne registration, 2026-10-13
- **Backup** - records lived only in one browser; a fresh backup needed 3 taps and a file hunt. Fix: data saved on the phone itself (app storage, survives restarts) + one-tap Share backup (Files, Mail, AirDrop). TODO
- **Clustered searches** - 35 searches sent on 3 days; ORP expects at least 2 every week. Fix: week strip showing weeks under 2 in amber + reminder when a week is short by Thursday. TODO
- **Deadline** - proofs due before the 5th of the next month, easy to miss. Fix: reminders on the 1st and the 4th, with the month's count. TODO
- **Job-Room entry** - every search re-typed by hand into Job-Room. Fix: Job-Room view, one card per search, a Copy button next to each field in Job-Room's order. TODO
- **ORP fields missing** - tracker had no address, contact person, phone, work rate, contact method, ORP result words. Fix: those fields, prefilled defaults (electronic, full time) so a normal entry is still 3 fields. TODO
- **Paper forms** - ORP mails form 716.007 "Preuves de recherches" as Word files to print. Fix: one tap makes the filled 716.007 PDF for any month, or for "avant chômage" (the 3 months before registration). TODO
- **Rejections out of date** - statuses only changed by pasting each email. Fix: keep paste-an-email; app-wide "results" sorting so pending ones older than 4 weeks are flagged for a check. TODO
- **Status words** - tracker said applied/rejected, ORP wants "en suspens / entretien / engagement / négatif". Fix: export maps statuses to ORP words automatically. TODO
